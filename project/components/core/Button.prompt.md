The salon's action element — uppercase Manrope on a hard-edged rectangle, used for every booking CTA.

```jsx
<Button variant="primary" size="lg" href="#book">Book an appointment</Button>
```

- `primary` is mauve with a long shadow and lifts 2px on hover (darkens to plum). Use once per section, never twice side by side.
- `deep` is the plum form used inside light form cards ("Request my appointment").
- `ghost` is the outlined secondary; `light` is the blush button used on plum panels.
- Labels are sentence-case words set uppercase by CSS, never ending in punctuation. Minimum height is 44px regardless of size.
